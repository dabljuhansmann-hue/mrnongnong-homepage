# Mr. NongNong – Homepage (Entwurf Stil H)

Startseite, Shop, Produktseiten und Warenkorb in einer Datei (`index.html`), dazu Bilder und Videos im Ordner `img/`.

## Auf GitHub Pages veröffentlichen
1. Auf github.com ein neues Repository anlegen (z. B. `mrnongnong-homepage`, „Public“).
2. „uploading an existing file“ wählen und den **Inhalt** dieses Ordners hineinziehen: `index.html`, den Ordner `img` und diese `README.md`. Danach „Commit changes“.
3. Im Repository: **Settings → Pages** → bei „Branch“ `main` und `/ (root)` wählen → **Save**.
4. Nach ein bis zwei Minuten ist die Seite unter `https://DEINNAME.github.io/mrnongnong-homepage/` erreichbar.
